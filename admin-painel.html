📖 Como funciona

  1. User cadastra com nome buscado → trigger calcula score 0-100
  2. Score ≥ 30 → bot Telegram te avisa com 3 botões: ✅ É ELE / ❌ Não é / 🤔 Ver mais
  3. Tu confirma → role vsx_b setada no perfil dele
  4. Próximo login dele → botão 🌊 sutil aparece no canto, leva pra Aurora narrar em 3 atos
  5. Aurora explica → família, app, convite pra virar Mago dev
